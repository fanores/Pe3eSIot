# Pe3eSIot

Pe3eS - Internet of Things

# Install package

```bash
#!/bin/bash
pip3 install -r requirements
```

# Run Tests

```bash
#!/bin/bash
pytest
```

# Run Tests with Coverage

```bash
#!/bin/bash
pytest --cov=./lib --cov-report=html --cov-branch
```
